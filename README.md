# College Admission Management Website

Created by Hasini M. | First Year CSE (AI)

## Files
- `index.html` — webpage structure and content
- `style.css` — styling and responsive layout
- `script.js` — demo application form, status tracker, and admin dashboard interactions

## Run locally
1. Download or extract all three files into the same folder.
2. Open `index.html` in a web browser, or open the folder in Visual Studio Code and use Live Server.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published website link to appear in Settings → Pages.

Note: This is a front-end demo. Application data is saved in the current browser's local storage; it is not sent to a real college server. Do not upload real personal information or documents.
